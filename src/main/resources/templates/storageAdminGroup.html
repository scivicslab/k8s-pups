Storage

{#if active}

Shared file storage, {storageSize}, {pvc}

Making the storage smaller takes it away first: stop the tools that use it. The size is a Lustre project quota that only an administrator of the file system can lower; this page shows the commands.

{#else if shrinkTo}

Taken away to be made smaller: {storageSize} → {shrinkTo} ({revoked}).

{#if shrinkCommands}

Run these on a007 as an administrator of the file system. The controller can neither run them nor check the result.

  1. Check the space used: {shrinkCommands.check}
    The value under "kbytes" must not be more than {shrinkCommands.newLimitKib} (= {shrinkTo}). If it is, do not go on: ask the group to delete files, or cancel.
  2. Lower the limit: {shrinkCommands.lower}
    Run the first command again: "blimit" must now show {shrinkCommands.newLimitKib}.
  3. Press Continue: the storage is given back at {shrinkTo}.
{#else}

The recorded PV has no Lustre project quota; the commands cannot be shown. Cancel the shrink.

{/if}
{#if shrinkCommands}
